# planner

برنامه‌ریز شخصی فارسی (PWA) با تقویم شمسی، مدیریت کارها، گزارش ادمین و تم رنگی قابل تنظیم.

## انتشار روی GitHub Pages

1. محتویات این پوشه را در ریشه یک مخزن GitHub قرار دهید (پوشه `public` باید در ریشه مخزن باشد).
2. تغییرات را روی شاخه `main` ثبت و Push کنید.
3. در مخزن GitHub به مسیر **Settings → Pages** بروید و در قسمت **Build and deployment → Source** گزینه **GitHub Actions** را انتخاب کنید.
4. از بخش **Actions** اجرای workflow با نام **Deploy planner to GitHub Pages** را بررسی کنید. پس از موفقیت، آدرس سایت در همان صفحه نمایش داده می‌شود.

## نکته درباره اطلاعات

کارها، دسته‌ها، قالب گزارش و تم انتخاب‌شده در `localStorage` همان مرورگر و همان آدرس سایت ذخیره می‌شوند. پاک‌کردن داده‌های مرورگر یا تغییر دامنه می‌تواند دسترسی به داده‌های محلی قبلی را از بین ببرد؛ پیش از چنین کاری خروجی/نسخه پشتیبان بگیرید.

## اصلاح نسخه نهایی

- اصلاح جایگزینی متغیرهای `{{DATE}}`، `{{TASKS}}` و `{{COUNT}}` در گزارش ادمین.
- تبدیل شکست‌خط‌های ذخیره‌شده به‌شکل `\\n` به خط جدید واقعی برای سازگاری با قالب‌های قبلی.
- افزایش نسخه کش PWA برای دریافت نسخه اصلاح‌شده پس از انتشار.

## تغییرات نسخه v4

- اصلاح جابه‌جایی کارها با دستهٔ ⠿: کارت‌ها هنگام کشیدن دیگر در DOM جابه‌جا نمی‌شوند (که باعث قطع لمس می‌شد)؛ فقط با انیمیشن جابه‌جا می‌شوند و هنگام رها کردن ترتیب ذخیره می‌شود.
- افزودن بخش «عقب‌افتاده» در صفحهٔ امروز با دکمهٔ «انتقال همه به امروز» (قابل بازگردانی).
- افزودن فیلتر «عقب‌افتاده» در لیست کارها.
- افزایش نسخه کش PWA به v12.

## تغییرات نسخه v5

- ساعت و مدت برای هر کار، نمای زمانی روزانه (در صفحهٔ امروز) و هشدار تداخل زمانی.
- ویرایشگر زیرکار با دکمه‌های ↑ ↓ ✕؛ آرشیو کارهای انجام‌شدهٔ قدیمی (فیلتر «آرشیو»).
- پروژه/هدف با درصد پیشرفت (تب «اهداف»).
- عادت‌ها با تقویم ماهانهٔ شمسی و streak.
- تکرار در روزهای مشخص هفته.
- چیدمان واکنش‌گرا: موبایل، تبلت (نوار بالا، لیست چندستونه) و دسکتاپ (منوی کناری، لیست‌های چندستونه، فرم به‌صورت پنجرهٔ وسط صفحه).
- جابه‌جایی کارها با ⠿ در چیدمان چندستونه هم کار می‌کند.

## تغییرات نسخه v6

- تقویم: چیدمان دسکتاپ/تبلت اصلاح شد (خانه‌های بزرگ‌تر، نام مناسبت داخل هر روز، پنل کناری جزئیات).
- مناسبت‌ها و تعطیلات رسمی: روزهای تعطیل و جمعه‌ها قرمز؛ لیست مناسبت‌های ماه و روز انتخاب‌شده.
- تعطیلات مذهبی ۱۴۰۵ دقیق (طبق تقویم رسمی)؛ سال‌های دیگر تعطیلات ثابت شمسی دقیق و مناسبت‌های قمری تقریبی (علامت ≈).
