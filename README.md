# planner

برنامه‌ریز شخصی فارسی (PWA) با تقویم شمسی، مدیریت کارها، گزارش ادمین و تم رنگی قابل تنظیم.

## انتشار روی GitHub Pages

1. محتویات این پوشه را در ریشه یک مخزن GitHub قرار دهید (پوشه `public` باید در ریشه مخزن باشد).
2. تغییرات را روی شاخه `main` ثبت و Push کنید.
3. در مخزن GitHub به مسیر **Settings → Pages** بروید و در قسمت **Build and deployment → Source** گزینه **GitHub Actions** را انتخاب کنید.
4. از بخش **Actions** اجرای workflow با نام **Deploy planner to GitHub Pages** را بررسی کنید. پس از موفقیت، آدرس سایت در همان صفحه نمایش داده می‌شود.

## نکته درباره اطلاعات

کارها، دسته‌ها، قالب گزارش و تم انتخاب‌شده در `localStorage` همان مرورگر و همان آدرس سایت ذخیره می‌شوند. پاک‌کردن داده‌های مرورگر یا تغییر دامنه می‌تواند دسترسی به داده‌های محلی قبلی را از بین ببرد؛ پیش از چنین کاری خروجی/نسخه پشتیبان بگیرید.

## اصلاح نسخه نهایی

- اصلاح جایگزینی متغیرهای `{{DATE}}`، `{{TASKS}}` و `{{COUNT}}` در گزارش ادمین.
- تبدیل شکست‌خط‌های ذخیره‌شده به‌شکل `\\n` به خط جدید واقعی برای سازگاری با قالب‌های قبلی.
- افزایش نسخه کش PWA برای دریافت نسخه اصلاح‌شده پس از انتشار.
